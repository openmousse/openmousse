# 学习台的课

> **有 OpenMousse 的 MCP 工具时（工具名里带 openmousse，比如 openmousse__study）就不用 shell**：study_ctl.py → study，args 放命令里脚本名后面的词（一个词一项），agent 填你的 id。没有这些工具就照原样在 shell 里跑命令。

每门课有一份**课程档案**：每一节的节号、日期、主题、要读的，作业和考试，考试怎么考、用户喜欢怎么学。学习台（电脑上 `<服务器>/study`、app 里学习看板上的「学习台」）按它排每一节、查材料齐没齐、生成学习页和学习路线；作业和考试进「今天」和你的截止表。**用户在学习台向导右边、app「对话」里跟你说的是同一个线程。**

```bash
S="python3 $HOME/.openmousse/repo/server/study_ctl.py"
$S courses                  # 有哪些课
$S show <课>                 # 每一节（带 id）、截止、要问的、待归节的文件
```

## 用户说哪里不对 → 直接改（能撤销，不用问）

先 `show` 看清现在是什么样，再改，改完一句话说清改了什么（回复下面会出一张「改了课程结构」的卡，用户能撤销，改过的地方在学习台上标黄）：

- 挪日期：`$S session update <课> 4 --date 2026-10-16 --time 10:00`
- 加一节（后面的自动顺延）：`$S session add <课> --topic "嘉宾讲座 Guest lecture" --date 2026-10-27`（给了日期就按日期插；也可以 `--after 7`）
- 去掉一节：`$S session remove <课> 8`（后面的往前挪一个号；文件夹和学习页留着，撤销就回来）
- 换这一节要读的：`$S reading set <课> 5 "教材第 6 章"`；加一篇：`$S reading add <课> 2 "Kahneman & Tversky (1979)"`
- 找不到的阅读先跳过：`$S reading skip <课> 2 <阅读 id>`（学习页会写明没读到）
- 作业和考试：`$S ddl add <课> --title "期末考试" --due "2026-12-08 09:00" --kind exam`；改 `ddl update`，交了 `ddl update <课> <id> --done`
- 读大纲时拿不准的（`show` 里「要问用户的」）：用户回答了就 `$S answer <课> <问题 id> "第 6 章"`
- 学习页想换写法（「更短」「多举例」「先讲直觉」）：`$S style <课> "…"`，以后每一节都照着写；已经写好的问一句要不要重写（`generate … --rewrite`）
- 改错了：`$S undo <课>`（撤销最近一次；`$S log <课>` 看改动号）

一句话里有几处要改的，一处一条命令，别漏；日期按用户所在时区写 YYYY-MM-DD。

## 用户在对话里发来课件、大纲

- 对话里的附件有 id（消息里写着）。课件：`$S file <课> --upload <附件 id>`，按文件名归到每一节，归不了的告诉用户在学习台上点「归到…」或者直接说是第几节（`--session 3`）。
- 大纲：`$S syllabus <课> --upload <附件 id>`（或 `--url`），一两分钟后 `show`，把读出来的节数、截止和要问的告诉用户。
- 缺的阅读用户让你去找：只找公开能下载的（作者主页、开放获取、Google Scholar 上的 PDF），下载到你的工作区后 `$S file <课> --file <路径> --session 2`；找不到就说找不到，建议先跳过。**不要绕开学校的登录或付费墙。**

## 还没有这门课

用户说「这学期有一门行为经济学，大纲在附件里」：`$S create "Behavioural Economics" --learn zh,intuition`，再按上面读大纲，然后带他走：核对每一节 → 放材料 → 生成。也可以让他在电脑上打开学习台点「加一门课」，一样的五步，旁边就是和你的这段对话。

## 生成

- 只生成**材料齐了**的节（`check` 里是「齐了」的）；没齐的先告诉用户缺什么、去哪找，他明确说不等了才 `--force`。
- `$S generate <课> 3 4`：写学习页 → 排学习路线 → 闪卡和小测。一节几分钟，写好一节对话里会记一行。
- 不要自己动手写学习页、改学习页文件或挪课件文件夹：都经 study_ctl.py，学习台才对得上。

## 撤不回的

删一门课：`$S delete <课>` 只出一张收件箱卡，用户点了同意服务器才删。用户没说要删，别提议删。
