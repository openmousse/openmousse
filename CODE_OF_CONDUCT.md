# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be kind, assume good intent, no harassment or personal attacks, keep discussions about the work. Reports go to the maintainer by email at hello@openmousse.ai (not in a public issue); they will be handled confidentially.

本项目遵守 [Contributor Covenant](https://www.contributor-covenant.org/zh-CN/version/2/1/code_of_conduct/) 2.1 版。一句话：友善、假定善意、不骚扰不攻击、只讨论事情本身。
